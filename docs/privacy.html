Privacy Policy

Brixel Upload

Effective date: 2 November 2026  ·  Single-user internal tool

What this tool is

Brixel Upload is a command-line script used solely by the channel owner (Tobias Burri) to upload videos to the Brixel YouTube channel via the YouTube Data API v3. It is not a public application and has no other users.

Data collected

The tool accesses the owner's YouTube account via OAuth 2.0 to upload videos and set scheduling metadata (title, description, publish date, thumbnail). No data from any third party is accessed, stored, or transmitted.

OAuth credentials

An OAuth token is stored locally on the owner's machine in a file readable only by the owner (mode 0600). It is never shared with any other service or person.

Third parties

No analytics, advertising, or tracking services are used. The only external service this tool communicates with is the YouTube Data API (Google LLC).

Data retention

No user data is retained beyond the OAuth token stored locally. Revoking access via Google Account settings immediately invalidates that token.
